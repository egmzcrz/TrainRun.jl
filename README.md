# TrainRun.jl

[_Live Demo_ (dummy data inside folder `data`)](https://egmzcrz.github.io/trainrun/)

**TrainRun.jl** is a simple Train Run Simulation Engine written in Julia. It calculates the continuous speed, time, force, and energy profiles of a train traveling along a specified track layout.

**For a more professional and comprehensive implementation of a Train Simulation Engine see: <https://github.com/railtoolkit/TrainRuns.jl>**

![Simulation Output](example_plot.svg "Simulation Output")

## **Physics Implementation**

The simulation core calculates the train's trajectory by evaluating physical forces at discretized points along the track. It resolves kinematics by running a forward pass to apply maximum tractive effort and a backward pass for safe braking. The final profile relies on the minimum speeds found between the two passes.

The net force acting on the train is calculated using:

$$F_\text{net}=F_\text{traction}-R_\text{roll}-R_\text{slope}-R_\text{curve}$$

* **Effective Mass**: Accounts for the rotational inertia of the rolling stock:

$$m_\text{eff}=m (1 + I_\text{rot}/100)$$

* **Rolling Resistance**: Uses the Davis equation to calculate the baseline resistance of the train as a function of velocity:

$$R_\text{roll}= A+ B v+ C v^2$$

* **Slope Resistance**: Resistance generated by vertical track gradients:

$$R_\text{slope} = m g \text{sin}\theta \approx m g \text{tan}\theta$$

* **Curve Resistance**: Resistance generated by horizontal track curvature (Röckl's empirical formula):

$$R_\text{curve} = m g \frac{A}{r-B}$$

* **Tractive and Braking Effort**:
  * Maximum tractive effort is interpolated from a velocity-force map, addressing both constant force and constant power regimes.
  * Maximum braking effort uses a braking curve table, referencing ERA ERTMS braking curves.
  * Both tractive and braking limits are constrained by an adhesion limit based on the empirical Curtius-Kniffler equation.

## **How to Run from the Terminal**

You can run the engine directly from your terminal using Julia. The script accepts command-line arguments to specify the track geometry, the train properties, and simulation parameters.

**Basic Execution:**

```bash
julia TrainRun.jl --geometry path/to/track.csv --train path/to/train.yaml --show --out path/to/saved/plot.svg
```

See the `data` directory for CSV and YAML file examples.

### **Command-Line Arguments**

| Flag | Argument | Required | Description |
| :---- | :---- | :---- | :---- |
| \--geometry, \-g | String | **Yes** | Input CSV track geometry file. Must contain 5 columns: pk\_m, vel\_kmh, curve\_m, slope\_‰, station\_name. |
| \--train, \-t | String | **Yes** | Input YAML file containing rolling stock information. |
| \--reverse, \-r | None | No | Flag to process the track direction in reverse. |
| \--ppkm | Int | No | Number of discretization points per kilometer. Default is **1000**. |
| \--dwell | Float64 | No | Dwell time at stations in seconds. Default is **0.0**. |
| \--out, \-o | String | No | Path to output the resulting plot as a PDF/PNG/SVG file. |
| \--show, \-s | None | No | Flag to display the generated plots on screen. |
